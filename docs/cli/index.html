Commands

One CLI, everyday checks.

Run the same checks locally, on staged files, or in CI. Add --cwd <dir> before a command to run it against another project directory.

Lint and format

Command Use
arch-lint lint [paths] Run ESLint, plus ruff and mypy when Python projects are configured. ESLint flags pass through.
arch-lint format [paths] Check formatting with Prettier and ruff.
arch-lint format:write [paths] Write Prettier and ruff formatting changes.
arch-lint fix Run lint fixes, then format writes.
arch-lint check Run lint, format, and architecture checks in order. 
arch-lint check
arch-lint check --skip-arch
arch-lint lint src/routes --max-warnings 0

--no-python skips Python tools. --python-only runs only those tools for lint and format, and leaves architecture rules out of check.

Architecture rules

Command Use
arch-lint arch Run enabled architecture rules.
arch-lint arch --rule a,b Run selected rule IDs or aliases.
arch-lint arch --list List the registered rules.
arch-lint arch --update-baseline Record current findings as tolerated debt.
arch-lint arch --format json Write machine-readable findings.
arch-lint arch --graph --format mermaid Write a dependency diagram.

Supported report formats include text, JSON, SARIF, GitHub Actions, GitLab, metrics, and Mermaid. Use arch-lint arch --help for the current flag list.

To report worsening numeric metrics as new findings, set baselineMode to worsening and refresh the baseline once with arch-lint arch --update-baseline. The configuration guide explains the version 5 baseline and refresh requirements.

CodeFlow

arch-lint codeflow analyze
arch-lint codeflow verify
arch-lint codeflow audit

Analyze writes a report, blast radii, and churn hotspots under .codeflow/. Verify checks findings against the files on disk. Audit writes an account of analysis findings and their verdicts.

Team workflow

arch-lint staged
arch-lint commit-msg .git/COMMIT_EDITMSG
arch-lint hooks install
arch-lint hooks status

Staged checks lint and format changed files, then run architecture rules over the project. Hooks install pre-commit, pre-push, and commit-message checks. Use arch-lint init --ci to add a GitHub Actions workflow.

MCP server

arch-lint mcp

This starts the Model Context Protocol server over standard input and output. Its tools include check_violations, analyze_change, get_dependencies, get_architecture, analyze_file, and get_callgraph. The older archlint_* tool names are available too. Change analysis can inspect the current git worktree, including deleted and renamed source paths.

A scan can filter the returned findings to one file. Its total, new, debt, fixed, and scanned counts remain project-wide, and the response marks that scope as project.
